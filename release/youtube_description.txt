TITLE:
FastWebScrape: Real-Time Native AVX2 HTML Scraping & CleanText LLM Engine (Java 17+ & SIMD) 🚀

DESCRIPTION:
Showcasing the raw extraction capabilities of FastWebScrape, the high-throughput native HTML parsing and tag-stripping engine of the FastJava ecosystem. Watch FastWebScrape ingest live Wikipedia articles concurrently via Java Virtual Threads and extract clean plain text, headers, metadata, and hyperlinks in microsecond bursts without creating DOM trees or garbage-collection objects.

FastWebScrape executes directly over raw byte buffers using optimized C++ AVX2 vector SIMD instructions at the native JNI layer, eliminating the memory and GC overhead associated with traditional JVM HTML parsers like JSoup or JDK RegEx.

TECHNICAL HIGHLIGHTS:
- Zero-Allocation CleanText Parsing: Strips scripts, stylesheets, comments, and tags at gigabytes per second directly into LLM-ready text with intelligent paragraph and boundary preservation.
- Native AVX2 SIMD Speed: Scans raw HTML payloads in microseconds, achieving 2.4x - 3.2x faster throughput than standard JDK regex parsers.
- Multi-Article Streaming Ingestion: Downloads and processes heavy live web payloads concurrently without thread starvation.
- Structured Element & Metadata Harvesting: Fast isolation of headings (H1-H6), article links (hrefs), and JSON-LD structured data blocks.
- FastANSI 120-Column Terminal HUD: Clean dark-gray framing and bold white metric highlights.
